# Assignment 1 - Bangun Datar

## Deskripsi

Assignment 1 merupakan latihan dasar Pemrograman Berorientasi Objek menggunakan Java dengan studi kasus **Bangun Datar**.

Program menggunakan class `BangunDatar` untuk merepresentasikan objek bangun datar dan `BangunDatarDemo` sebagai program untuk menjalankan dan menguji objek tersebut.

## File

- `BangunDatar.java` - Class yang digunakan untuk merepresentasikan bangun datar.
- `BangunDatarDemo.java` - Class utama untuk menjalankan program.

## Konsep yang Dipelajari

- Class
- Object
- Attribute
- Method
- Constructor

## Tujuan

Memahami konsep dasar Object-Oriented Programming (OOP), khususnya cara membuat class, membuat object, serta menggunakan attribute dan method pada Java.

## Cara Menjalankan

Compile program:

```bash
javac BangunDatarDemo.java
