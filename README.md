# PBO2K26 - Java Programming Assignments

Repository ini berisi kumpulan tugas dan latihan **Pemrograman Berorientasi Objek (PBO)** menggunakan bahasa Java.

Project ini dibuat sebagai bagian dari pembelajaran konsep dasar hingga penerapan **Object-Oriented Programming (OOP)**, seperti class, object, constructor, inheritance, encapsulation, dan polymorphism.
