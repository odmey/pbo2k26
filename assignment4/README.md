# Assignment 4 - Account & Bank

## Deskripsi

Assignment 4 menggunakan studi kasus **Account dan Bank** untuk menerapkan konsep Object-Oriented Programming yang lebih lanjut.

Program terdiri dari beberapa class yang saling berhubungan, yaitu `Account`, `BankAccount`, `Customer`, dan `BankMain`.

## File

- `Account.java` - Class dasar yang merepresentasikan Account.
- `BankAccount.java` - Class yang merepresentasikan akun bank.
- `Customer.java` - Class yang merepresentasikan customer.
- `BankMain.java` - Class utama untuk menjalankan program.

## Konsep yang Dipelajari

- Inheritance
- Encapsulation
- Constructor
- Access Modifier
- Relasi antar-class

## Tujuan

Memahami bagaimana beberapa class dapat saling berhubungan dalam sebuah sistem serta menerapkan konsep inheritance dan encapsulation dalam Java.

## Cara Menjalankan

Compile program:

```bash
javac BankMain.java
