# Assignment 2 - Bank

## Deskripsi

Assignment 2 menggunakan studi kasus **Bank** untuk menerapkan konsep Object-Oriented Programming dalam Java.

Program terdiri dari class `Bank` dan `BankDemo` yang digunakan untuk membuat dan menjalankan objek Bank.

## File

- `Bank.java` - Class yang merepresentasikan objek Bank.
- `BankDemo.java` - Class utama untuk menjalankan program.

## Konsep yang Dipelajari

- Class
- Object
- Attribute
- Method
- Constructor

## Tujuan

Memahami penerapan konsep class dan object pada sebuah studi kasus sederhana serta memahami bagaimana object dapat digunakan dalam sebuah program Java.

## Cara Menjalankan

Compile program:

```bash
javac BankDemo.java
