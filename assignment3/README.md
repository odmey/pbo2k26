# Assignment 3 - Inheritance

## Deskripsi

Assignment 3 membahas konsep **Inheritance** dalam Pemrograman Berorientasi Objek menggunakan Java.

Program terdiri dari beberapa class yang digunakan untuk memahami hubungan dan pewarisan antar-class.

## File

- `Ayah.java` - Class yang digunakan dalam penerapan inheritance.
- `Rumah.java` - Class yang digunakan sebagai bagian dari program.
- `Main.java` - Class utama untuk menjalankan program.

## Konsep yang Dipelajari

- Inheritance
- Parent class
- Child class
- Pewarisan attribute dan method
- Hubungan antar-class

## Tujuan

Memahami bagaimana sebuah class dapat mewarisi attribute dan method dari class lainnya menggunakan konsep inheritance.

## Cara Menjalankan

Compile program:

```bash
javac Main.java
